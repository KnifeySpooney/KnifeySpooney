## 🔪 KnifeOps: Open Source Security Suite

I develop and maintain **KnifeOps**, a branded suite of open-source cybersecurity tools designed for real-world operational needs:

### 🎯 [KICC](https://github.com/KnifeySpooney/KICC) - KnifeOps InfoSec Command Center
**The unified OSINT & intelligence platform**

KICC consolidates the fragmented "browser tab" workflow into a single, privacy-first desktop environment. It combines threat intelligence aggregation, data manipulation utilities, and report generation into one streamlined application.

**Key Features:**
- 📡 **Threat Radar**: RSS-powered threat intelligence with automated severity scoring
- 🎨 **IG Studio**: Social media-style briefing generator for non-technical stakeholders
- 🔧 **SH4DOW Workbench**: Suite of forensic utilities (D3CON defanging, LOG-X analysis, CYPH3R encoding/decoding)
- 🔒 **100% Local Execution**: Zero cloud dependencies, your data never leaves your machine
- ⚡ **Built with Electron**: Cross-platform desktop application with a utility-first UI

### 👻 [SP3CTR](https://github.com/KnifeySpooney/SP3CTR) (Specter)
**Network traffic analyzer for enhanced clarity**

A network traffic analysis tool designed to cut through the noise and provide actionable insights with an emphasis on user experience and visual clarity.

### 🕵️ [SH4DOW](https://github.com/KnifeySpooney/SH4DOW) (Shadow)
**Modular honeypot & deception intelligence platform**

A flexible deception framework that allows security teams to deploy honeypots and gather threat intelligence from real attacker behavior.
